# 控制台第二批可用性改进 Implementation Plan

> **For agentic workers:** 使用既有工作区分工执行，保留第一批及用户尚未提交的改动。

**Goal:** 让评测范围、执行状态、列表顺序和下一步操作可理解、可操作。

**Architecture:** 复用现有 Vue 组件与模型评测读接口；排序在服务端分页前完成；不新增服务、依赖或持久化状态。

**Tech Stack:** FastAPI / Pydantic、Vue 3、Element Plus、pytest、Node test、Playwright。

**Spec:** 本聊天中用户批准的第二批范围。

## Constraints

- 不从执行状态推断模型健康或上线结论；保留“最新执行”和“最近成功证据”的不同含义。
- 未知时区不补造时间；按最后执行时间排序时，未知时间排最后。
- 达到任务读取上限只提示可能存在更早数据，不声称已确定截断。
- 保留空状态的事实说明与产品边界；不修改历史数据。

## Tasks

- [x] 主代理：模型列表服务端排序、覆盖单位与对比提示；列表和模型详情复用执行/证据状态展示；更新 API 文档及测试。
- [x] 主代理：任务中心数量上限提示和分页；用接口 limit+1 判断是否有更早数据，列表仍仅展示规定条数。
- [x] Claude：能力数据集名称、评测页空状态动作、刷新和中文文案、主题动作说明、移除开发导航、Element Plus 中文 locale。
- [x] 主代理：审查 Claude 改动，运行前端单元/构建/浏览器回归与后端测试，截图检查桌面和窄屏。

## Validation

- 排序跨页正确；同分稳定；未知时间不伪造为当前时间；非法排序参数被拒绝。
- 最近执行失败仍保留旧成功证据；未评测状态不重复描述。
- 任务数达到上限时，提示依据未筛选的源记录，分页和筛选一致。
- 空状态按钮打开原有配置，不提交；Suite 定位已有向导且保留表单。
- 中文选择标签、分页、三态主题动作与实际切换一致。

## Results

- 前端单元测试：51 项通过；生产构建（含 vue-tsc）通过。
- 浏览器完整回归：51 项通过；覆盖 375 / 768 / 1024 / 1440 宽度及亮暗主题。
- 相关后端与文档测试：20 项通过。
- 后端全量：使用 uv run --with tzdata pytest -q --tb=no，200 项通过、44 项失败；失败集合与第一批相同，涉及当前 Windows 环境缺少 EvalScope / Harbor 等依赖。未将全量验证标记为通过。
- API 变化为可选排序参数与读取时计算的 last_execution_at，不修改任务归档，无迁移要求。
