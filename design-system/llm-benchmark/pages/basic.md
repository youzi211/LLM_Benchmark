# 基础评测页覆盖规则

> 路由 `/basic`。更新于 2026-10-30，覆盖历史三列布局约定。

## 布局与配置

- PageHero 保留刷新数据与新建基础评测；配置进入 `EvaluationWorkspace` 抽屉，不占主区。
- 主区为最近任务列表与结果详情两栏，≤1279px 纵向排列。列表仅统计当前返回的记录。
- 抽屉展示当前模型、评测计划和指标多选；默认计划与提交参数不变。
- 成功提交后关闭抽屉、跟踪任务；关闭抽屉不重置已填参数。

## 列表与结果

- 列表合并模型名与任务 ID，状态和人类可读耗时单独列；真实零耗时保留。
- 支持多选重跑/对比、清空勾选，选择少于两条时对比按钮禁用。
- 详情展示执行完成、异常、跳过数与耗时，不输出自动上线结论。
- 指标结果、报告预览、任务信息分别置于标签中。任务异常与运行提示保持可见。
- 指标优先显示中文名称，并保留稳定的指标 ID；摘要不再强制截断为两行。
- 保留 TaskTimeline、报告链接、取消任务与 `task_id` 深链接。

## 验证

- 单元测试保护时长/状态展示，隔离浏览器测试覆盖提交、指定指标、取消、重跑、对比及响应式。
- API 失败不得显示为“暂无任务”；详情失败保留新选中任务的缓存，而非上一次详情。
