# Overview 页覆盖规则

> 本文件覆盖 MASTER.md 中与概览页相关的规则。更新于 2026-10-30。

## 布局

- 顶部 PageHero：小标签、中文主标题、全部模型统计范围说明，右侧为刷新数据与新建评测。
- 主体纵向间距 24px；标题不重复增加底部外边距。
- KPI 桌面四列，≤1180px 两列；数字与单位分开排版。
- 主区两列：`minmax(0, 1.8fr) minmax(280px, 1fr)`，间距 24px。
- 左侧：运行中任务、最近结束任务；右侧：服务健康、评测快捷入口。
- ≤900px 主区单列，右侧内容变为两列；≤600px 全部内容单列，KPI 保持两列。
- 移动端底部导航的安全距离由工作台页脚保留，不额外堆叠大块主区留白。

## 视觉

- 浅灰背景、白色面板、细边框，蓝色突出主要操作；亮暗主题共用语义 token。
- 标题使用系统无衬线字体；指标使用等宽数字特性；任务 ID 使用等宽字体。
- 静态卡片不做悬停位移；可点击条目使用背景/文字颜色反馈，保留键盘焦点。

## 数据与交互

- KPI 全部来自现有全量统计接口；不从截断后的最近任务列表重新计算。
- 平均耗时按量级显示毫秒、秒、分钟、小时，悬停显示原始毫秒值。缺失、无效或负数显示“—”。
- 最近任务优先展示模型名、评测线、状态，保留 ID 与完成时间，通过真实链接进入任务详情。
- ServiceHealth 仅显示传入的真实健康状态，不提供演示数据；保留已接入的重试与配置快捷操作，顶部另有环境配置入口。
- RunningTasks 保留进度与已用时间；空态提供三条评测线入口。
- 保留加载态、空态、部分失败、全部失败提示；不添加虚构趋势图或评测指标。
